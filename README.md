# BPL Dream 11

## A Brief Description

Here is a player selection site. It will help the franchises choose their preferable player easily considering the player's role in cricket. It contains a navbar, banner, available players, selected players, newsletter, and a footer section.

## Technologies Used

HTML
Tailwind css
React JS
Node JS
Surge

## 3 Key Features of the Project

1. It has a Claim Free Credit button which Provides necessary money for all user.
2. It has a Choose Player button which add a player in selected player and subtracted money from free coins, chosen by user.
3. It has a Delete button which functions to remove a player from selected player and returned money in free coins. Eventually every button functionality shows a toast alert.
